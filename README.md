## GitHub 归档与版本

公开仓库：https://github.com/SherlockGy/dots-knowledge-archive

本仓库持续积累和更新按主题整理的知识档案，并维护统一索引与归档约定，不发布完整聊天记录。2026-10-24 首次将已整理内容导出到 GitHub；远端提交历史从这次发布开始，不等同于保留此前本地提交的原始 SHA 或更早历史。

后续根据用户当次归档 / 更新授权新增主题或更新已有档案，并同步维护索引，提交前确认公开范围，不自动发布聊天或其他资料。提交和推送分别取得用户明确授权后执行；推送后回读远端文件，核对内容及版本。GitHub 是可重新获取的远端副本，本地工作副本不是唯一保存位置。
